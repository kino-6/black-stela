## T13 — early difficulty: 無購入Lv1 vs 購入済み, B1F

Codex: "数値ゲートは確認済みだが、初見の敗北が施設利用を学ばせる手触りまでは判定できない。新規Lv1・無購入／
購入済みを並べた短いプレイ記録が必要." Two records, both driving the REAL combat engine.

### (a) Descent-sim oracle — `npm run sim:balance -- --world default --level 1 --sizes 6,3,1`

`none`-heal (pessimistic one-push lower bound), startLevel 1. `naive` = a party that bought/read nothing
(starter loadout); `mid`/`prep` = the gear the shop sells; size 1 = the extreme no-facility (solo) case.

```
  PREPARE-OR-WIPE : naive clears @Lv8, prepared @Lv1  →  levelsSaved=7
  PARTY-SIZE      : full(6) clears @Lv1, solo(1) @Lv15

  TROUGH (lowest mid-fight HP%, none-heal, startLv=1) vs act target:
    floor        target          6p·mid  6p·naive   6p·prep    3p·mid    1p·mid
    b1f           85%- 65%          64%       10%       64%       64%      WIPE
    b2f           85%- 65%          64%        5%       64%       64%         —
    b5f           60%- 42%          68%      WIPE       68%       68%         —
```

Reading: a full **無購入** party (`6p·naive`) is dragged to a **10% HP trough on B1F** and **wipes by B5F** —
it cannot clear the run at Lv1 (naive only clears comfortably by Lv8). A **購入済み** party (`6p·mid/prep`)
sits at a healthy **64%** and clears the descent. A **solo** Lv1 **wipes B1F** outright. Money spent on gear
is the difference between a 10% scrape and a 64% cruise — the facilities are the lever.

### (b) Real browser play — `npx playwright test player-clear`

`tests/e2e/player-clear.spec.ts` plays the B1F marker trek through visible controls only (no purchases):
a **full starter party survives, arriving hurt**; its header comment (lines 13-15) records that a **lone
Lv1 wipes** the same trek (the extreme no-facility case). Matches the sim: no-purchase is survivable-but-
brutal for a full party and lethal for a thin one.

Caveat (per `.claude/skills/drpg-balance`): the sim omits gimmick hazards, status and back-row exposure, so
**real play runs tougher than these troughs** — the 10% B1F scrape is an upper bound on the no-purchase
party's comfort. Numeric gates (`descentSim.test`, `difficultyGate`, `preparationGate`) stay green.
