## 1. 【要アート判断】玄室ランドマークのビジュアル承認 — `Tasks.md` の唯一の未クローズ項目

- **背景:** プレイテストで玄室ランドマークが「説明のつかない緑の物体」に見える、と指摘。
- **実施済み（コード）:** `godot/scripts/dungeon/dungeon_renderer.gd`
  - `_add_chamber_landmarks`: chamber accent を約60%脱彩度（緑の発光プロップ → 色味を帯びた石として読ませる）
  - `_add_chamber_floor_seal`: 床シールの不透明度 0.88→0.74（置かれた円盤ではなく床に嵌め込まれたディテールへ）
- **依頼:** verdant の玄室を実機で確認し、**「部屋として読めるか（プロップでないか）」を判断**。
  - OK なら `Tasks.md` の「玄室 landmark visual tuning」を `[x]` にして完了記録へ。
  - NG なら **床シールのテクスチャをリテイク**（緑寄りのシール画そのものが原因の可能性大 → 中立な嵌め込み石へ）。
    アセット基名の contract は既存の chamber-seal に合わせること。
