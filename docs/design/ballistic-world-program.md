# 銃器DRPG世界プログラム（仮称：封鎖線）

Status: **世界・アート・銃は terminal-line として出荷済み。** 本プログラムの世界／アート（3帯・敵6種・拠点・銃）は既に
terminal-line world として実装・出荷された。残っていた未実装分は W3a の資源管理ルール（共有弾薬・警戒度）だった。

> **決定（user 2026-08-12）: 通常攻撃での弾薬管理は行わない。** W3a の中核だった「共有弾薬で通常攻撃の弾を管理し、撃つ／
> 温存を選ぶ」core loop は不採用（user:「弾薬管理しないと言ったはず」）。よって §4/§5/§7 の弾薬前提（§40「銃は弾を払って
> 事故率を下げる手段」§52「共有弾薬」等）は**廃案**。残る検討余地は user 承認待ちの2点のみ — (i) 特殊行動（技）への別軸コスト
> （有り得るが必須でない）、(ii) 弾薬非依存の「警戒度＝発砲の騒音でフロア危険度↑」を単独採用するか。それ以外に新規実装は無い。

この文書は、Default と Verdant を変更せずに第三の世界を育てるための設計入口だった（以下は当初構想の記録）。

## 1. 目指す体験

> 封鎖された都市地下網を、限られた弾薬と異能を抱えた探索隊が踏破する。撃てば道は開くが、音と消耗が次の
> 区画の危険を呼び込む。

Default の乾いた石と贖罪、Verdant の生命侵食とは別に、**近現代の生活圏が地下で壊れた場所**を描く。
銃は単に高威力の武器ではなく、探索資源・位置取り・遭遇圧を変える選択にする。特定作品の設定・固有名詞・
敵・物語を模倣しない。

### 具体コンセプト（W0たたき台）

地上の都市で大規模な避難が起きてから十七年。地下の広域避難施設〈**封鎖線**〉は、地上へ通じる非常用の
**零番線**だけを残して閉鎖された。生存者の拠点「乗換広場」には、零番線が今も夜ごと一度だけ走るという
無線が入る。探索隊は列車の終点にある中央隔離局を目指し、誰がこの放送を続け、なぜ外へ出る経路が封じられたかを
確かめる。

これは「崩壊した東京風の街」でも「ネオンのサイバーパンク」でもない。日常のために設計された公共インフラが、
避難・検疫・配給という目的を失ったまま、**ひそかに人を選別し続けている**世界である。超常は派手な魔界ではなく、
記録・指紋・声・死者の避難登録が実体を得る不穏さとして扱う。

プレイヤーの最初の目的は世界を救うことではなく、零番線に乗るための「運行鍵」を集めること。第一幕の終わりに、
その鍵が退避民を隔離局へ送り返す装置でもあると判明し、進む理由が反転する。

### プレイヤーが感じるべき差

| 要素 | 封鎖線での役割 |
| --- | --- |
| ダンジョン | 地下鉄、雨水貯留槽、居住区、行政隔離層。石の迷宮を着色しない。 |
| 探索資源 | 弾薬、予備部品、医療品、端末電力。補給の判断が押す／帰るを作る。 |
| 戦闘 | 射線、装填、制圧、近距離での不利、騒音。六人編成の前後列を射撃距離と防衛で意味づける。 |
| 超常 | 異能・儀式・端末侵入を、魔法の名称変更でなく「銃で解けない問題」の手段にする。 |
| 拠点 | 退避区画の整備工房、診療所、闇市場、情報端末。町の機能は既存コマンドを利用しつつ世界固有の演出を持つ。 |
| 敵 | 暴走保安機、変異生物、武装した探索者、区画に残った住民の残滓。人型だけに偏らずシルエットを分ける。 |

### コア・ループ（最初の実装で守るもの）

1. 拠点で、弾薬・医療・防具のうち「今回の探索で足りなくなる一つ」を買う。
2. 探索中は、静かな近接／異能で弾を温存するか、銃で確実に危険を早く消すかを選ぶ。
3. 発砲は弾を減らすだけでなく、その階の**警戒度**を上げる。警戒度が高いほど徘徊遭遇の質が悪くなり、
   迂回・帰還・補給ロッカーを探す価値が上がる。
4. 駅の補給ロッカー、保守端末、避難扉は「弾を使わず進める／危険を下げる」探索報酬として配置する。
5. 帰還後、弾を撃ったことで得た戦利品と情報を、次の銃・防具・端末用具へ変える。

銃は最強の通常攻撃ではない。**弾を払って、目の前の事故率と探索時間を下げる手段**である。異能は弾薬と競合せず、
回復・索敵・妨害・警戒度の操作を担う。これにより、全員が同じ銃を連射するだけのパーティにならない。

### 最小固有ルール仕様（W3aで実証する範囲）

最初から装填数、部位狙い、遮蔽物、武器改造、敵AIを一度に導入しない。第一幕で必要なのは次だけである。

| ルール | 最小仕様 | しないこと |
| --- | --- | --- |
| 共有弾薬 | パーティの所持品に「汎用弾」を持つ。銃タグの行動は1発消費し、0発なら選べない。 | キャラ別の弾倉、手動リロード、銃種ごとの弾薬を初期実装しない。 |
| 銃撃 | 装備中の銃タグで通常攻撃より安全な遠距離／命中補正を得る。ただし防御的な近接職の役割を奪わない。 | 常に最大火力の万能攻撃にしない。 |
| 警戒度 | フロアごとの0〜3。戦闘で最初に銃を撃った時だけ+1。遭遇テーブルの重みを段階的に危険側へ寄せる。 | 一発ごとに敵を即時スポーン、進行不能な強制戦闘、隠し数値を置かない。 |
| 警戒低下 | 補給ロッカー／保守端末／帰還で1段階下がる。端末は資源か探索成功を要求する。 | 無料の常時リセット、休憩ボタンだけでの全回復。 |

UIは迷宮HUDに「残弾」と警戒度3段階の**意味のある名称**（静穏／注意／警報など）を常時出す。生の数値だけにせず、
警戒度が上がった直後には一行で「発砲音が通路へ響いた。注意が向いている。」と知らせる。操作は既存の戦闘コマンド
選択・所持品・探索アクションの範囲で完結し、マウス照準を要求しない。

### 第一層で教える一つの判断

最初の5〜8分で、二択を一度だけ明確に出す。

- 直進ルート: 近いが、暴走した保安機2体を銃で止めないと前衛が危険。弾を2発使えば安全に通れる。
- 迂回ルート: 弾を使わず通れるが、浸水した改札を回り込み、医療品か補給ロッカーを探す必要がある。

どちらも正解にする。直進したプレイヤーは「銃が命を買う」こと、迂回したプレイヤーは「地図と探索が弾を買う」ことを
学ぶ。初手で全滅させず、第一層終盤の守護者前で残弾・負傷・警戒度が重なり、帰還して整える判断を作る。

### 10層の三幕

| 幕 | 層 | 場所と物語 | 主な圧力 | 到達時の変化 |
| --- | --- | --- | --- | --- |
| I: 入口は生活圏だった | F1–F3 | 乗換広場の外れ、地下鉄改札、浸水ホーム。無線と運行鍵の手掛かりを追う。 | 弾不足、近距離の保安機、狭い射線。 | 鍵の一つが「帰還者を再隔離する」命令であると分かる。 |
| II: 施設は人を管理する | F4–F6 | 雨水処理区、物資配給庫、医療記録庫。避難民の記録が敵や扉を動かす。 | 警戒度、射撃人型、端末妨害、複数経路。 | 零番線は脱出便でなく、中央隔離局へ人を回収する巡回線だと判明する。 |
| III: 零番線の終点 | F7–F10 | 中央隔離局外縁、列車管制、地上昇降路、零番線の終端。F9で「地上へ帰す」記録と向き合い、F10で放送の主へ届く。 | 弾の最終管理、遠近混成、警戒度を下げる最後の余地。 | 放送の主と対面し、零番線を止める／運行を引き継ぐ／地上へ開く選択へ至る。 |

ループ／近道／報酬行き止まりとして地形に埋める。

## 2. 先に決めること／決めないこと

### W0で決めること

- 正式タイトル、world id、地下へ入る動機、最終到達点。
- 銃撃と騒音を「新しい決定的ルール」にするか、既存の技・アイテム・敵能力の表現に留めるか。
- 弾薬を共有資源にするか、武器種ごとの消耗品にするか。無限弾薬や単なるMP置換にはしない。
- 第一層で学ぶ一つの判断（例：安い弾を撃ち切って進むか、近接で温存して帰るか）。

### この段階で決めないこと

- 個々の敵数値、武器名、フロア本文、実装言語や画面レイアウト。
- 既存世界の敵・所持品・職・戦闘式の変更。
- 外部作品由来の固有設定。

## 3. 新パック作成前の隔離契約

1. **W0承認までは文書とアセットブリーフだけ。** `content/worlds/`、世界レジストリ、共有ルール、Godot画面を
   変更しない。
2. 承認後も新規パックは `content/worlds/<new-id>/` に閉じる。Default／Verdant のデータやアセットを共有名で
   上書きしない。新アセットは world-own basename を使う。
3. 銃・騒音などが既存ルールで表現不能と判明した時だけ、別タスク W4a としてルール拡張を独立させる。
   W4a は TS oracle → export → Godot parity → セーブ互換の順で行い、世界アセット作業と同じコミットに混ぜない。
4. 各段階はその段階専用のブランチ／コミットで完結させる。未完成パックは世界選択画面へ登録しない。

## 4. アセット・プログラム

アセットは「色替え」ではなく構造の置換として発注する。生成・採用は一度に行わず、各バッチを実機で置いて
承認してから次へ進む。強い全画面フラッシュ、過度な発光、既存アセットの無断上書きは禁止。

### 共通アートディレクション

**キーワード:** 1990〜2000年代の公共地下施設、雨、摩耗、避難の痕跡、古い案内サイン、低い天井、
冷えた金属。人間が使うために作られた場所が、人間を守らなくなった感じ。

- **材質:** つや消しの白灰タイル、くすんだステンレス、黒いゴム床、錆びた塗装鋼、濡れたコンクリート、
  曇ったアクリル板。傷・水垢・貼り紙の剥がれは入れるが、ランダムなノイズで表面を埋めない。
- **光:** 鈍い蛍光灯、非常灯の残光、保守灯。局所的な赤／青は警告や端末の意味を持つ時だけ使う。
  ネオン街・常時点滅・レンズフレア・白いフラッシュは禁止。暗部でも敵と導線は読める露出にする。
- **色:** 上層は灰白＋くすんだ黄、 中層は青緑の湿気＋錆茶、深層は黒鉛＋鈍い群青＋非常時だけの暗い赤。
  鮮やかなシアン／マゼンタのサイバーパンク配色にはしない。
- **構図:** 第一人称の正面壁で読める大きな構造を置く。小さなUIアイコン風の落書き、宙に浮く粒子、
  HUDの下に隠れる床だけのランドマークに依存しない。
- **人物／敵:** 生存者は実用的な防寒具・作業着・雨具。長い黒コート、軍用装備の過密、銃口を常にこちらへ
  向けるポーズを避ける。敵は人型以外を最低半数にし、形・高さ・接地で識別させる。

### A0 — ルック開発（最初に承認する小バッチ）

- 壁／床テクスチャ各3帯：

### A1 — 第一幕のプレイ用アセット

- 敵6種の base + hurt（小型害獣／警備機／射撃人型／近接人型／支援異形／第一層守護者）。
- 武器・弾薬・医療品・鍵端末のアイコン群。戦利品スチル1枚。
- 第一幕の部屋ごとのランドマーク3種（駅改札、浸水ホーム、補給ロッカー等）。

**受入:** 6敵が戦闘レーンで接地・識別でき、base/hurtを含めて既存敵と混同しないこと。

### A2 — 全10層の量産

- 各三層帯に敵4種以上、玄室用の守護者、固有の扉・階段・背景差分。
- 重要な宝、ボス、帰還地点のスチルを必要な箇所だけ追加。

**受入:** 各層で最低3つの異なるシルエットと、深度に応じた建築・危険の変化が実機で読めること。

アセットの最終ファイル名・寸法・配置先は、W1で作る
`content/worlds/<new-id>/ART.md` を唯一の契約とする。既存の [`docs/art/common.md`](../art/common.md) に従う。

## 5. 作業順序と完了条件

1. **W0 — 世界の核を承認する。** この文書の未決定事項を埋め、3幕・資源循環・最小固有ルールを一枚にする。
2. **W1 — パック骨格とアセット契約。** 新 world pack の空の正規形、`world.md`、`ART.md`、設計文書を作る。
   レジストリにはまだ登録しない。
3. **W2 — A0を配置して視覚承認。** テクスチャと構造物を一層の小さな検証マップへ置き、実機でレビューする。
4. **W3a — 最小固有ルールを実装する。** 共有弾薬・警戒度・銃タグの最小仕様を、TS oracleからGodotへ
   parity-portする。世界アセットの量産とは同じコミットに混ぜない。

## 6. 各段階のゲート

- **W0:** 設計レビュー。世界の一文、三幕、銃の意思決定、既存世界との差分を承認する。
- **W1:** scenario pack schema / content validation。未登録なので通常プレイへの影響がないこと。
- **W2:** `npm run export:godot`、該当のGodotレンダー検証、1280/1920の実機キャプチャ。比較画像で既存世界との非同一性を確認する。
- **W3a:** 新 Command のTS golden trace、`verify_parity`、save round-trip、既存二世界の回帰。
- **W3b/W4:** world registry / maze quality / encounter coverage / `descentSim` / treasure / e2e の新世界版。
- **W5:** `npm run gate:final`、`npm run gate:migration`、Godot clean boot、コントローラ経路、実機プレイレビュー。

## 7. W0で承認する境界

第一幕の核は、**有限の弾薬を消費して安全と時間を買う資源管理**とする。射線・射程・制圧は銃器世界に似合うが、
最初のスライスでは基本攻撃の距離／命中補正に留め、遮蔽・部位狙い・個別装填などの戦術拡張はW4の候補に分離する。

W0で残す判断は、(1) 「封鎖線」と「零番線」を正式名称として採用するか、(2) 主人公たちが零番線を
止める／引き継ぐ／地上を開くという終幕の選択を採用するか、(3) 警戒度を静穏／注意／警報の三名称で進めるか、の三つである。
